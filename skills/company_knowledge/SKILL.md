# 锐博公司知识只读查询

此运行时 skill 供 planner、知识问答和 critic 使用。它只允许查询组织、组织别名、组织关系、业务、资质、法律引用和人力资源业务口径；身份、租户与资料权限由数据库 RLS 执行。

查询时由小模型按问题域选择同目录的一份完整资源文件：

- `company_relations.md`：组织关系定义；
- `company_business.md`：公司业务和资质口径；
- `hr_business_terms.md`：人力资源行业业务口径；
- `legal_terms.md`：法律口径和出处规则；
每份类别文件内同时维护业务口径、适用 schema 和只读查询示例。组织关系、公司业务、人力资源业务和法律问题可由模型多选类别。模型路由失败时加载四份类别文件，并记录降级日志。

不得生成写入、DDL、锁定读取、跨 schema、多语句或带副作用函数的 SQL。查询没有结果表示当前授权范围内未找到记录，不表示事实为假。查询失败也不得解释为没有冲突。
