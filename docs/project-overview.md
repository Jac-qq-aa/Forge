# Forge 项目概览

Forge 是内容研究与生成平台，支持知乎、微信公众号和手动素材输入。所有素材进入同一深度流程：事实研究与审核、大纲确认、正文生成、对话微调和定稿。

系统结构、状态和部署方向见 [technical-architecture.md](technical-architecture.md)，RocketMQ、Outbox、Worker 扩容和知乎浏览器池的完整实施说明见 [high-concurrency-async-architecture.md](high-concurrency-async-architecture.md)，关键并发代码讲解见 [high-concurrency-code-guide.md](high-concurrency-code-guide.md)，HTTP 与 WebSocket 接口见 [api-reference.md](api-reference.md)。
