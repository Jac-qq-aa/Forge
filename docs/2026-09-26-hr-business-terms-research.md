# 人力资源行业业务口径：公司知识库首批表设计与权威来源调研

调研日期：2026-09-26  
适用项目：Forge 公司知识库 / Text2SQL 只读检索  
来源边界：仅采用全国人大、国务院、司法部、人力资源社会保障部、国家统计局、国家税务总局、商务部、国家市场监督管理总局及全国标准信息公共服务平台的一手资料。

## 结论

首批不应把所有内容塞进现有 `legal_references`。建议新建五张深表：业务术语主表、法定合规义务表、地区/时效参数表、分类代码表、来源证据表。这样 Text2SQL 可以明确回答“定义是什么”“如何计算”“哪个地区、哪个时间有效”“是强制规则还是推荐标准”“来源条款在哪里”。

首批可安全入库 27 条：法律强制口径 17 条、统计口径 5 条、行业服务口径 5 条。社保缴费比例、社保缴费基数上下限、公积金最高比例、最低工资金额等均有地区和年度差异，不应生成全国统一数值；招聘转化率、离职率、招聘成本、人才测评合格线等企业 KPI 也没有统一国家定义，应作为公司自定义口径另行审批。

## 推荐数据表

所有表均应带 `space_id`，受现有租户/RLS 约束；Text2SQL 账号只授予 `SELECT`。来源正文和业务记录分离，便于法规更新后新增版本而不覆盖历史事实。

### `hr_business_terms`：业务术语主表

| 字段 | 类型建议 | 说明 |
|---|---|---|
| `id` | UUID PK | 记录主键 |
| `space_id` | UUID FK | 公司知识空间；RLS 隔离键 |
| `term_code` | TEXT | 稳定业务编码，如 `HR_DISPATCH_RATIO` |
| `term_name` | TEXT | 口径名称 |
| `domain` | TEXT | 招聘、派遣、社保、公积金、薪酬个税、合同工时、培训测评、灵活用工、外包等 |
| `term_type` | ENUM/TEXT | `legal_mandatory`、`statistical`、`industry_service`、`company_defined` |
| `definition` | TEXT | 经法源约束的规范化定义 |
| `calculation_rule` | TEXT | 公式或判断规则；没有公式时为空 |
| `unit` | TEXT | 人、元、天、百分比等 |
| `applicable_scope` | TEXT | 主体、人员类型、业务场景、地区 |
| `exclusions` | TEXT | 明确不适用项和易混淆项 |
| `mandatory_level` | TEXT | 强制、统计填报、推荐性国家标准、政策分类、公司内部 |
| `status` | TEXT | draft / verified / superseded |
| `effective_from` / `effective_to` | DATE | 口径有效期；不覆盖旧版本 |
| `version` | TEXT | 法规/标准版本号 |
| `source_id` | UUID FK | 指向 `hr_term_sources` |
| `reviewed_by` / `reviewed_at` | UUID / TIMESTAMPTZ | 人工复核轨迹 |

建议唯一键：`(space_id, term_code, effective_from, version)`。

### `hr_compliance_obligations`：法定动作与阈值

| 字段 | 类型建议 | 说明 |
|---|---|---|
| `id`, `space_id` | UUID | 主键与隔离键 |
| `obligation_code` | TEXT | 稳定编码 |
| `actor_type` | TEXT | 用人单位、用工单位、派遣单位、人力资源服务机构、扣缴义务人等 |
| `trigger_event` | TEXT | 录用、开展业务、发薪、加班、解除合同等 |
| `required_action` | TEXT | 必须完成的动作 |
| `deadline_value` / `deadline_unit` | NUMERIC / TEXT | 15 日、1 月等 |
| `threshold_expression` | TEXT | 可执行但不直接运行的表达式，例如 `dispatch_workers / total_workers <= 0.10` |
| `exception_rule` | TEXT | 例外与前置程序 |
| `article_clause` | TEXT | 条款号 |
| `effective_from` / `effective_to` | DATE | 有效期 |
| `source_id` | UUID FK | 权威来源 |

### `hr_regional_parameters`：地区和年度参数

| 字段 | 类型建议 | 说明 |
|---|---|---|
| `id`, `space_id` | UUID | 主键与隔离键 |
| `term_id` | UUID FK | 对应主口径 |
| `region_code` | TEXT | 国家行政区划代码；全国用 `CN` |
| `employment_type` | TEXT | 全日制、非全日制、灵活就业等 |
| `parameter_name` | TEXT | 缴费比例、基数下限、最低工资等 |
| `value_numeric` / `value_text` | NUMERIC / TEXT | 数值或枚举值 |
| `unit` | TEXT | 元/月、元/小时、百分比等 |
| `valid_from` / `valid_to` | DATE | 参数有效期 |
| `source_id` | UUID FK | 必须来自当地政府/主管部门正式文件 |

禁止只以 `(term_id, region_code)` 唯一，因为同一地区存在多档、多人群和多年度参数。建议唯一键包含 `employment_type, parameter_name, valid_from`。

### `hr_classification_codes`：国家分类和服务分类

| 字段 | 类型建议 | 说明 |
|---|---|---|
| `id`, `space_id` | UUID | 主键与隔离键 |
| `classification_system` | TEXT | 如 `GB/T 4754-2017`、服务外包统计分类 |
| `code` / `parent_code` | TEXT | 分类编码及父编码 |
| `name` | TEXT | 分类名称 |
| `definition` | TEXT | 官方分类解释 |
| `inclusions` / `exclusions` | TEXT | 包含/不包含项目 |
| `version` | TEXT | 分类版本 |
| `valid_from` / `valid_to` | DATE | 有效期 |
| `source_id` | UUID FK | 来源 |

### `hr_term_sources`：法源与证据

| 字段 | 类型建议 | 说明 |
|---|---|---|
| `id`, `space_id` | UUID | 主键与隔离键 |
| `source_kind` | TEXT | law、regulation、department_rule、national_standard、statistical_system、policy |
| `title` | TEXT | 文件/标准全名 |
| `issuing_authority` | TEXT | 发布机构 |
| `document_number` | TEXT | 文号或标准号 |
| `source_url` | TEXT | 官方原始地址 |
| `article_clause` | TEXT | 条款或章节定位 |
| `published_on` / `effective_from` / `effective_to` | DATE | 发布时间和效力 |
| `source_quote` | TEXT | 最短充分证据摘录，不放搜索摘要 |
| `content_hash` | CHAR(64) | 抓取正文校验值 |
| `retrieved_at` | TIMESTAMPTZ | 获取时间 |
| `verification_status` | TEXT | verified / pending / superseded |
| `supersedes_source_id` | UUID FK nullable | 新旧法源链 |

## 不宜凭空生成或冒充国家口径的内容

- **社保与公积金全国统一费率**：法律只确定制度和缴费责任，具体比例、基数、档次按地区、年度和人员类型变化。
- **“灵活用工”等同于某一种合同或税率**：国务院政策只列举个体经营、非全日制、新就业形态等方式；“灵活用工”不是可一刀切套用的单一劳动法律关系。[《国务院办公厅关于支持多渠道灵活就业的意见》](https://app.www.gov.cn/govdata/gov/202007/31/461367/article.html)
- **外包天然不构成劳动关系或等同派遣**：应依合同履行、人员管理、报酬支付、风险承担等事实判断；不能只凭合同标题。现行机构管理规则明确禁止以外包名义实际按派遣实施。[《人力资源服务机构管理规定》](https://www.mohrss.gov.cn/xxgk2020/gzk/gz/202306/P020230630664858664234.pdf)
- **招聘成功率、招聘周期、离职率、缺勤率、人均效能、培训 ROI**：没有统一国家计算分子、分母和观察窗口；可以建立 `company_defined` 版本，但须记录公司批准人、公式、数据范围和版本。
- **人才测评合格线、信效度和常模**：必须来自具体测评工具的技术手册、经验证数据与适用人群，不得依据网络文章编造。
- **市场薪酬、岗位价格和“行业平均值”**：必须记录样本范围、样本量、统计期、币种、税前税后、城市、职级和发布者；搜索摘要或招聘广告不能升级为“国家口径”。
- **标准全文中的细则**：全国标准平台只展示元数据时，仅能入库标准号、名称、状态、发布/实施日期；未经合法获取的标准正文不得由模型补写。

## 入库与检索规则

1. 首批记录全部以 `verified` 入库，但标准类仅把平台可确认的元数据标为已核验；正文条款另设 `pending_fulltext`。
2. 每次查询优先级建议：现行法律/行政法规/部门规章 > 现行国家统计制度 > 现行国家标准 > 公司自定义口径 > 网络检索。
3. 冲突时先比较效力层级、发布日期、施行日期、适用地区和适用主体；旧记录保留并标记 `superseded`，不覆盖删除。
4. 参数查询必须包含 `region_code` 和查询日期；缺任一项时返回“需要地区/日期”，不猜测。
5. 公式字段只用于解释和受控计算，不允许 Text2SQL 将表达式拼成写操作或动态 SQL。
6. 证据应返回表名、记录 ID、条款号和官方 URL，使前端显示为 `数据库 → hr_business_terms / hr_compliance_obligations / hr_regional_parameters → 官方来源`。
